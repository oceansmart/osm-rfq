📌 텍스트 또는 URL 목록에서 다음 두 가지 정보를 모두 자동 추출해줘:

1) Figma node-id 추출 및 변환
2) "Connected to server in channel: xxx" 형태의 채널명 추출

---

[1] node-id 처리 규칙
- 입력되는 URL 또는 텍스트에서 "node-id=" 뒤의 값을 추출한다.
- node-id 형식은 항상 "숫자1-숫자2" 형태이다.
- 이를 "숫자1: 숫자2" 형태로 변환한다.
- 변환된 결과만 테이블로 표시한다.

예:
node-id=55-5099 → 55: 5099

---

[2] channel 처리 규칙
- 텍스트에서 "Connected to server in channel:" 뒤에 오는 문자열을 추출한다.
- 공백 포함한 전체 채널명을 그대로 추출한다.
- channel 값이 여러 개면 모두 리스트로 표시한다.
- node-id와 동일한 출력 테이블에 포함하지 않고 별도 테이블로 분리한다.

예:
Connected to server in channel: otoglwnd → otoglwnd

---

[출력 형식]

### 🧩 변환된 Figma node-id 테이블
| 변환 결과 |
|-----------|
| {a: b} |
| {c: d} |

### 🔌 추출된 Channel 정보 테이블
| Channel |
|---------|
| {channelName} |
| {channelName2} |

---

이제 내가 URL이나 텍스트를 아무 순서로 넣어도,
위 규칙에 따라 node-id와 channel 정보를 자동으로 추출해서 출력해줘.
