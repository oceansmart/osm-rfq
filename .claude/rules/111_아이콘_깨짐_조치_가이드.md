# 아이콘 깨짐 문제 해결 가이드

> **작성일**: 2025-11-23
> **대상**: Frontend 개발자
> **관련 프로젝트**: OSM RFQ

---

## 문제 증상

- 브라우저에서 아이콘이 표시되지 않음 (깨진 이미지 아이콘 표시)
- 콘솔에 `404 Not Found` 에러 발생
- 특정 SVG 파일을 찾을 수 없다는 에러 메시지

---

## 원인 분석

### 1. 파일명 불일치

**증상**: 코드에서 참조하는 파일명과 실제 파일명이 다름

**예시**:
```tsx
// 코드에서 참조
<Image src="/icons/rfq-list/title/search.svg" />

// 실제 파일명
search-icon.svg  // ❌ 불일치
```

### 2. 파일 경로 오류

**증상**: 아이콘 파일이 잘못된 경로에 위치

**예시**:
```
// 코드에서 참조
/icons/rfq-list/title/filter.svg

// 실제 위치
/icons/common/filter.svg  // ❌ 경로 불일치
```

### 3. 파일 누락

**증상**: 아이콘 파일이 아예 존재하지 않음

---

## 해결 방법

### 방법 1: Untitled UI React 컴포넌트 사용 (권장)

**장점**:
- ✅ TypeScript 타입 안전성
- ✅ 일관된 디자인 시스템
- ✅ SVG 파일 관리 불필요
- ✅ React 컴포넌트로 최적화

**단계**:

#### 1.1. 필요한 아이콘 찾기

```bash
# Untitled UI 아이콘 목록 확인
ls node_modules/@untitledui/icons/dist/ | grep -i "search"
```

**주요 아이콘 예시**:
- `SearchLg` - 큰 검색 아이콘
- `SearchMd` - 중간 검색 아이콘
- `ChevronDown` - 아래 화살표
- `HelpCircle` - 도움말 아이콘
- `FilterLines` - 필터 아이콘

#### 1.2. 컴포넌트 Import

```tsx
import { SearchLg, ChevronDown, HelpCircle, FilterLines } from "@untitledui/icons";
```

#### 1.3. 기존 Image 태그 교체

**Before (SVG 파일)**:
```tsx
<Image
  src="/icons/rfq-list/title/search.svg"
  alt=""
  width={20}
  height={20}
/>
```

**After (React 컴포넌트)**:
```tsx
<SearchLg size={20} />
```

#### 1.4. 전체 예시

```tsx
import React from "react";
import Image from "next/image";
import { SearchLg, ChevronDown, HelpCircle, FilterLines } from "@untitledui/icons";
import styles from "./styles.module.css";

export default function MyComponent() {
  return (
    <div>
      {/* Search Icon */}
      <div className={styles.searchIcon}>
        <SearchLg size={20} />
      </div>

      {/* Dropdown Arrow */}
      <div className={styles.dropdownArrow}>
        <ChevronDown size={20} />
      </div>

      {/* Help Icon */}
      <div className={styles.helpIcon}>
        <HelpCircle size={16} />
      </div>

      {/* Filter Icon */}
      <div className={styles.filterIcon}>
        <FilterLines size={20} />
      </div>
    </div>
  );
}
```

### 방법 2: SVG 파일 직접 관리

**장점**:
- ✅ 커스텀 아이콘 사용 가능
- ✅ Next.js Image 최적화 활용

**단점**:
- ❌ 파일 관리 필요
- ❌ 파일명 불일치 위험

**단계**:

#### 2.1. 파일 존재 여부 확인

```bash
# 특정 폴더의 아이콘 파일 확인
ls -la frontend/public/icons/rfq-list/title/
```

#### 2.2. 파일명 일치 확인

**코드에서 참조**:
```tsx
<Image src="/icons/rfq-list/title/search.svg" />
```

**실제 파일명 확인**:
```bash
cd frontend/public/icons/rfq-list/title/
ls | grep search
# 출력: search-icon.svg
```

#### 2.3. 파일명 수정

**옵션 A: 파일명을 코드에 맞게 변경** (권장)
```bash
cd frontend/public/icons/rfq-list/title/
mv search-icon.svg search.svg
mv ms-excel.svg ms_excel.svg
```

**옵션 B: 코드를 파일명에 맞게 수정**
```tsx
// Before
<Image src="/icons/rfq-list/title/search.svg" />

// After
<Image src="/icons/rfq-list/title/search-icon.svg" />
```

#### 2.4. 파일 추가 (누락된 경우)

1. **Figma에서 Export**:
   - Figma 디자인 파일 열기
   - 아이콘 선택
   - 우클릭 → Export → SVG 선택
   - 저장

2. **파일 저장 위치**:
   ```
   frontend/public/icons/[component-name]/[icon-name].svg
   ```

3. **예시**:
   ```
   frontend/public/icons/rfq-list/title/search.svg
   frontend/public/icons/layout/home.svg
   ```

## 네이밍 규칙

### SVG 파일명 규칙

1. **kebab-case 사용** (권장):
   ```
   search.svg
   chevron-down.svg
   help-circle.svg
   ```

2. **snake_case 사용** (특정 케이스):
   ```
   ms_excel.svg
   ```

3. **피해야 할 패턴**:
   ```
   ❌ searchIcon.svg (camelCase)
   ❌ SearchIcon.svg (PascalCase)
   ❌ search-icon-1.svg (숫자 suffix)
   ```

### 폴더 구조 규칙

```
public/
├── icons/
│   ├── layout/           # Layout 컴포넌트 전용
│   │   ├── header/
│   │   └── side-bar/
│   ├── rfq-list/         # RFQ List 컴포넌트 전용
│   │   └── title/
│   └── [component-name]/ # 각 컴포넌트별 폴더
└── images/
    └── [component-name]/
```

**중요**: 중복 파일명 방지를 위해 **반드시 컴포넌트별 폴더로 분리**

## 실전 예시

### 사례 1: RFQ List Title 아이콘 깨짐

**문제**:
```
404 Not Found: /icons/rfq-list/title/search.svg
404 Not Found: /icons/rfq-list/title/filter.svg
404 Not Found: /icons/rfq-list/title/chevron-down.svg
```

**실제 파일**:
```
search-icon.svg
dropdown-icon-1.svg
ms-excel.svg
```

**해결**:
```tsx
// Before (깨진 상태)
import Image from "next/image";

<Image src="/icons/rfq-list/title/search.svg" width={20} height={20} />
<Image src="/icons/rfq-list/title/filter.svg" width={20} height={20} />
<Image src="/icons/rfq-list/title/chevron-down.svg" width={20} height={20} />

// After (Untitled UI 사용)
import { SearchLg, ChevronDown, FilterLines } from "@untitledui/icons";

<SearchLg size={20} />
<FilterLines size={20} />
<ChevronDown size={20} />
```

**결과**: ✅ 모든 아이콘 정상 표시

## 추가 팁

### 1. 아이콘 누락 방지

프로젝트 시작 시 `.claude/rules/030-ui.md` 규칙을 따라 컴포넌트별 폴더 구조를 미리 생성:

```bash
mkdir -p frontend/public/icons/[component-name]
mkdir -p frontend/public/images/[component-name]
```

### 2. 일괄 파일명 변경

여러 파일의 하이픈을 언더스코어로 일괄 변경:

```bash
cd frontend/public/icons/rfq-list/title/
for file in *-*.svg; do
  mv "$file" "${file//-/_}"
done
```

### 3. Figma 아이콘 일괄 Export

Figma에서 여러 아이콘을 한 번에 Export:
1. 아이콘들을 Shift+클릭으로 다중 선택
2. 우클릭 → Export → SVG
3. 파일명 규칙에 맞게 Rename
