# OSM RFQ Documentation

Welcome to the OSM RFQ project documentation.

## 프로젝트 개요

OSM RFQ는 견적 요청 및 관리 시스템으로, Frontend와 Backend로 구성되어 있습니다.

## 📚 문서 구성

### Frontend
Next.js 기반의 프론트엔드 애플리케이션

- **[Frontend 개요](frontend/index.md)** - 프론트엔드 프로젝트 소개
- **[시작하기](frontend/getting-started.md)** - 개발 환경 설정 및 실행 가이드
- **[컴포넌트](frontend/components/index.md)** - 재사용 가능한 UI 컴포넌트
- **[디자인 시스템](frontend/design-system/index.md)** - 디자인 토큰 및 스타일 가이드

### Backend
API 서버 및 데이터베이스

- **[Backend 개요](backend/index.md)** - 백엔드 프로젝트 소개
- **[시작하기](backend/getting-started.md)** - 개발 환경 설정 및 실행 가이드
- **[API 문서](backend/api/index.md)** - REST API 엔드포인트
- **[데이터베이스](backend/database/index.md)** - 스키마 및 모델

## 🚀 Quick Start

### Frontend 개발 서버 실행

```bash
cd frontend
npm install
npm run dev
```

### Backend 개발 서버 실행

```bash
cd backend
# 향후 추가 예정
```

### 문서 서버 실행

```bash
# 루트 디렉토리에서
npm install
npm run docs:serve
```

## 🛠️ 기술 스택

### Frontend
- **Framework**: Next.js 14.2.33 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 3.4.1
- **Design System**: Figma Design Tokens
- **Testing**: Playwright
- **Documentation**: Storybook 9.1.13
