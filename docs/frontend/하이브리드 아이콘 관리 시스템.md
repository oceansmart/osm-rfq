# Icons Directory

## Current Architecture

This project uses a **hybrid icon management system**:

### 1. Primary Icons: @untitledui/icons (npm package)

**Location**: `node_modules/@untitledui/icons`
**Re-export**: [src/commons/components/icons/index.ts](../../src/commons/components/icons/index.ts)
**Total Available**: 1,100+ professionally designed SVG icons

#### Usage Example:

```tsx

import { ArrowRight, Plus, Download, Trash } from '@/commons/components/icons';

function MyComponent() {
  return (
    <button>
      <Plus size={20} color="#3A5CF3" />
      Next Step
    </button>
  );
}
```

#### Benefits:
- React components with TypeScript types
- Dynamic props: `size`, `color`, `className`
- Automatic tree-shaking (only used icons bundled)
- Easy updates via npm
- Consistent design language

#### Currently Used Icons (80+):
- **Navigation**: ArrowLeft, ArrowRight, ChevronDown, etc.
- **Actions**: Plus, Minus, Check, X, Edit, Trash, Save
- **Status**: AlertCircle, CheckCircle, InfoCircle
- **Communication**: Mail, MessageSquare, Phone, Send
- **Media**: Image, File, FileText, Folder, Video
- **User**: User, Users, UserPlus, UserMinus
- **UI**: Menu, Search, Filter, Settings, Calendar, Clock
- **Business**: ShoppingCart, CreditCard, DollarSign, BarChart

See full list in [src/commons/components/icons/index.ts](../../src/commons/components/icons/index.ts)

---

### 2. Custom Icons: /public/icons (this directory)

**Purpose**: Project-specific custom icons not available in @untitledui/icons

#### When to Use This Directory:
- Brand-specific logos (e.g., OSM RFQ logo)
- Custom illustrations
- Project-specific diagrams
- Icons not available in @untitledui/icons package

#### File Naming Convention:
```
/public/icons/
  ├── logo-osm-rfq.svg          # Brand logo
  ├── custom-workflow-icon.svg  # Custom illustrations
  └── category-specific/         # Group by feature
      ├── rfq-status-pending.svg
      └── rfq-status-approved.svg
```

#### Usage Example:

**Method A: Next.js Image Component (Recommended)**
```tsx
import Image from 'next/image';

function Logo() {
  return (
    <Image
      src="/icons/logo-osm-rfq.svg"
      alt="OSM RFQ Logo"
      width={120}
      height={40}
    />
  );
}
```

**Method B: Direct SVG Import**
```tsx
function CustomIcon() {
  return (
    <img
      src="/icons/custom-workflow-icon.svg"
      alt="Custom Workflow"
      className="w-6 h-6"
    />
  );
}
```

**Method C: Create React Component Wrapper**
```tsx
// src/commons/components/icons/custom.tsx
export function OsmRfqLogo({ size = 24 }: { size?: number }) {
  return (
    <img
      src="/icons/logo-osm-rfq.svg"
      alt="OSM RFQ"
      width={size}
      height={size}
    />
  );
}
```

## Icon Selection Guidelines

### Use @untitledui/icons when:
- Icon exists in the 1,100+ icon library
- Need dynamic sizing/coloring
- Want consistent design language
- TypeScript type safety required

### Use /public/icons when:
- Custom brand assets (logos, mascots)
- Project-specific illustrations
- Complex multi-color icons
- Static images that don't need props

## Adding New Custom Icons

### Step 1: Prepare SVG File
- Optimize SVG using [SVGO](https://jakearchibald.github.io/svgomg/)
- Remove unnecessary metadata
- Ensure viewBox is set correctly
- Use descriptive file names (kebab-case)

### Step 2: Add to /public/icons
```bash
cp my-custom-icon.svg /frontend/public/icons/
```

### Step 3: (Optional) Create React Component
For frequently used custom icons, create a wrapper:

```tsx
// src/commons/components/icons/custom.tsx
export function MyCustomIcon({
  size = 24,
  className = ''
}: {
  size?: number;
  className?: string;
}) {
  return (
    <img
      src="/icons/my-custom-icon.svg"
      alt="My Custom Icon"
      width={size}
      height={size}
      className={className}
    />
  );
}
```

### Step 4: Document in Storybook
Create a story for visual documentation:

```tsx
// src/commons/components/icons/custom.stories.tsx
export const CustomIcons: Story = {
  render: () => (
    <div className="flex gap-4">
      <MyCustomIcon size={32} />
      <OsmRfqLogo size={120} />
    </div>
  ),
};
```

## Migration Notes

### Why Not All Icons Are Here?

**Historical Context**: This directory was originally intended for static icon file management. However, the project adopted `@untitledui/icons` npm package for better developer experience:

1. **Type Safety**: TypeScript definitions included
2. **Dynamic Props**: Size/color changes without file duplication
3. **Maintenance**: Automatic updates via npm
4. **Developer Experience**: Auto-complete in IDE

### Current Directory Status

This directory is **intentionally empty** and serves as a dedicated location for **custom project-specific icons only**. All standard UI icons are managed via the npm package.

## Troubleshooting

### Icon Not Rendering from /public/icons

**Check 1**: Verify file path (must start with `/icons/`)
```tsx
// ✅ Correct
<Image src="/icons/logo.svg" />

// ❌ Wrong
<Image src="icons/logo.svg" />
<Image src="./icons/logo.svg" />
```

**Check 2**: Clear Next.js cache
```bash
rm -rf .next
npm run dev
```

**Check 3**: Check file permissions
```bash
ls -la public/icons/
# Should show -rw-r--r-- permissions
```

### Storybook Warning: "unable to find package.json for @untitledui/icons"

**Status**: Known harmless warning, does not affect functionality.

**Cause**: Storybook's react-docgen-loader attempts to find source files, but the package only provides compiled `dist/` files.

**Solution**: Already configured in [.storybook/main.ts](../.storybook/main.ts):
- TypeScript `propFilter` excludes @untitledui/icons props
- Webpack `warningsFilter` suppresses the warning

## Exception: Component-Specific Custom Icons

### Payment Icons (Input Component Integration)

**Location**: `src/commons/components/icons/*.tsx` (8 files)

**Purpose**: Credit card type detection icons for the Input component

**Files**:

- `amex-icon.tsx`, `visa-icon.tsx`, `mastercard-icon.tsx`
- `discover-icon.tsx`, `unionpay-icon.tsx`
- `apple-pay-icon.tsx`, `paypal-icon.tsx`, `stripe-icon.tsx`

**Why Not in /public/icons?**

- Used as React components with dynamic rendering
- Tightly integrated with Input component logic
- Require component-level props and state management
- Better TypeScript integration

**Usage**:

```tsx
import { VisaIcon, MastercardIcon } from '@/commons/components/icons';

<Input
  type="text"
  value={cardNumber}
  // Icons automatically displayed based on card type
/>
```

### Dot Icon (Badge Component Integration)

**Location**: `src/commons/components/badge/dot-icon.tsx`

**Purpose**: Badge dot indicator primitive

**Why Component-Specific?**

- Single-use utility (Badge component only)
- Simple SVG primitive (24 lines)
- No reuse across other components
