# OSM RFQ Frontend Documentation

Welcome to the OSM RFQ Frontend project documentation.

## Project Overview

This project is built with:

- **Next.js 14.2.33** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Figma Design Tokens** - Design system integration
- **Storybook** - Component documentation and testing
- **Playwright** - End-to-end testing
- **MkDocs** - Documentation system

## Quick Start

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Testing

```bash
npm run test:e2e
```

### Storybook

```bash
npm run storybook
```

## Documentation

This documentation is built with MkDocs Material theme and includes:

- Component documentation
- Design system guidelines
- Development workflows
- Testing strategies
