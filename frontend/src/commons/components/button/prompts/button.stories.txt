아래의 조건을 모두 적용하여, 아래의 요구사항을 모두 구현할 것.
구현 결과를 체크리스트로 반환할 것.

==============================================

조건-프로젝트) OSM RFQ 프로젝트 표준을 준수할 것.
            - Design System: Untitled UI PRO 기반
            - Styling: Tailwind CSS v4 + CSS Variables
            - Component Library: React Aria Components
            - Documentation: Storybook 9.1.13

==============================================

조건-파일경로) 참고할 TSX     파일경로: frontend/src/commons/components/button/index.tsx
조건-파일경로) 구현될 STORIES 파일경로: frontend/src/commons/components/button/index.stories.tsx

==============================================

핵심요구사항) Button 컴포넌트의 모든 variants를 Storybook Stories로 구현할 것.

구현 범위:
1. **Size Variants** (4가지)
   - sm, md, lg, xl

2. **Color Variants** (10가지)
   - Primary: primary, secondary, tertiary
   - Link: link-gray, link-color
   - Destructive: primary-destructive, secondary-destructive, tertiary-destructive, link-destructive

3. **State Variants**
   - Default, Hover, Disabled, Loading
   - Icon Leading, Icon Trailing, Icon Only

4. **Interactive Controls**
   - Storybook Controls로 모든 props 조작 가능
   - Args 기반 스토리 구성

==============================================

기술 요구사항:
- TypeScript strict mode 준수
- React Aria Components 통합 검증
- Untitled UI 디자인 토큰 활용 (--color-brand-*, --font-*, etc.)
- 접근성 (a11y) 검증 포함
